# BT Portfolio

Monochrome personal portfolio, built with HTML, CSS and JavaScript.

## Local preview
Open index.html or run `python -m http.server 8000` in the project directory and visit http://localhost:8000.

## Structure
- index.html: page structure
- assets/css/style.css: styles and responsive layout
- assets/js/data.js: project, certificate and skill data
- assets/js/main.js: tabs, scroll effects and draft copying
- assets/images: image storage
- assets/documents: public document storage

## Deploy
Push the contents of this folder to a GitHub repository. In Settings > Pages select Deploy from a branch, main, / (root). For Netlify use the repository root as publish directory; no build command is needed.

## Limitations
Portrait and certificates are placeholders. Contact form copies a draft, not sends email. No backend. Review personal information before publishing.
